# 大论文后续研究路线图

日期：2026-10-23。状态：**基于现有文件和文献提出的建议，尚未启动新实验，也未确定新增创新点成立**。返回 [项目地图](../../PROJECT_MAP.md)；配套 [论文阅读清单](READING_LIST_2026-10-23.md)。

本轮按用户说明将小论文作为已完成的研究基础；当前正文为 V7。新增文献及四个候选方向的比较见 [选线评估](THESIS_DIRECTION_ASSESSMENT_2026-10-23.md)，包括 Beat-SSL、ShapeEFM、BeatRhythm-TTA、TolerantECG、IECG 和 CODE-II 等。下文第 3 节仅作稿件归档参考，不是新的执行队列。

后续已形成[整体实验设计](EXPERIMENT_DESIGN_2026-10-23.md)和[主机 A 首批任务书草案](../experiments/THESIS_P0_20261023/TASKBOOK.md)，细化为 9 个多标签 LP、12 个匹配表示诊断和 1 个 HeartLang 下游验证；仅训练/验证数据，尚未下发或启动。该草案具体化了基准与诊断阶段，不表示下文候选新方法已实现或已证实。

## 1. 当前判断

后续以大论文新方法研究为重点：先补原生多标签任务基准，再集中验证一个与已有工作有清楚区别的方法假设。小论文已完成的框架与冻结实验作为研究基础。

**首选方法候选：可靠性约束的逐心拍形态—节律建模。** 研究问题是：在短记录、异常心拍与 R 峰定位不稳定时，如何保留有用的逐拍变化，避免平均心拍与粗粒度 RR 统计丢失信息，或将不可靠先验注入预训练？“平均会丢失诊断信息”在本项目中仍是假设，需要对照证明。

**备选候选：训练期导联质量感知的可变导联融合。** 它对应开题的多导联与复杂场景问题，但已有质量门控和跨导目标负结果，风险较高，适合先做瓶颈诊断。

**配套验证：原生多标签、未见噪声和独立数据源。** 这些能提高结论可信度，但增加数据集、换 sigmoid 或多画图本身通常不足以构成新的方法贡献。

## 2. 为什么这样选：现有证据

| 已核对的事实 | 对后续工作的含义 |
|---|---|
| V7 已形成 TRC + Beat-RR + 真实噪声增强联合框架；M4 相对 M0 的 CPSC LP AUPRC 约 +1.308 个百分点 | 不再把旧组件组合当作全新方向 |
| V7 中 M4−M6（在 TRC+噪声背景上加入 Beat-RR）约 −0.051 个百分点，CI 跨 0 | 需要解释何时生理辅助约束有用，不能假定再加 RR 头必然涨点 |
| `dv_dataset.py` 将 R 峰窗求平均，并回归 mean RR / SDNN / RMSSD；少于 3 峰无效 | 已有 R 峰缓存与心拍入口可复用，但逐拍形态、间期顺序与检测不确定性尚未充分表达 |
| V7 的 RR 置换与随机窗比较校正后不显著 | 现有结果未证实 RR 独立信息贡献或 R 峰对齐必要性；新研究应安排可证伪对照 |
| CPSC 原始多诊断真值已经找回；V7 补表 S4 是对既有单标签 softmax 分数的重评 | 不需重复宣称“首次找回真值”；真正缺口是使用原生多标签训练头、损失与验证集阈值 |
| W6 LCM 已判负；W7 频带功率比事后门控未满足干净性能约束 | 不重提为未做方向；若研究质量感知，必须改变机制并复核旧失败 |
| 噪声训练/测试片段互斥，但来自同一 NSTDB 和同类噪声 | 未见类型、独立噪声源或设备差异仍是明确验证缺口 |
| W9 FT10 已补齐；2026-10-20 裁决明确不补 M4b–Chapman FT10，不为效率表重训 | 小论文收尾优先修稿与证据对齐，不恢复这些旧补跑项 |

证据入口见 [PROJECT_MAP 的论文证据表](../../PROJECT_MAP.md)。本路线图不把历史报告的条件性判读模板当成统计结论。

## 4. P0：原生多标签与数据协议（先做）

### 问题与最小工作

保留同一记录的多个诊断，以 sigmoid + `BCEWithLogitsLoss` 建立原生多标签基准。先用标准 BCE，避免同时改类别重加权、损失、编码器与数据口径。

- **CPSC**：复用 `runlog/preds_archive/cpsc_multilabel/` 中现存真值，检查 record ID、split、类别顺序和重复记录。真值 CSV 与导出脚本的九独立列重排已随 2026-10-23 整理批入库；启动实施前仍先核对其内容。
- **PTB-XL**：从原始诊断标签与患者信息建立单独协议，核验所用版本的官方划分；不要继续把原生标签压成单一类别。先选择一个明确的多标签任务层级，完整记录映射。
- 患者 ID 可得时按患者分组；ID 不可得时清楚说明 record-level 与身份去重的限制，内容哈希不等于患者去重。
- 新任务另建数据 manifest / protocol ID / 结果目录，不覆盖小论文 CE 单标签结果。

### 最小比较与交付

先复用 M0、M4、M6 的冻结编码器训练多标签 LP 头，每个配置最终用 {0,2,4}，共 9 个头训练；特征与权重是否在当前机器可用需实施时检查。原生多标签特征评估成功后，再选择一个固定标签比例开展微调，不一开始铺开全网格。

输出 macro-AUPRC、macro-AUROC、逐类 AP、类支持数；F1 / sensitivity 的阈值只在验证集确定。报告单诊断和多诊断子集，避免总体均值掩盖共病样本。不要将新协议的绝对数值与小论文旧单标签表直接相减并归因于模型。

**交付**：数据契约、真值审计、划分 manifest、多标签 LP 表、训练及阈值配置、逐记录预测。此阶段属于必要基建和任务扩展，不能单独保证新的方法创新。

## 5. P1：可靠性约束的逐心拍形态—节律预训练（首选候选）

### 假设

一条记录由不同形态的心拍及其间隔组成。当前平均心拍会压缩逐拍差异，三项 RR 统计会压缩间隔顺序；但压缩也可能抑制噪声、提高稳定性。因此要检验的不是“序列必优”，而是**哪些记录需要逐拍信息，以及检测不可靠时如何使用这些信息**。

拟采用共享的小型心拍编码器保留 K 个心拍，显式输入 RR 序列和有效掩码；形态和节律分支分开表达，再与整段表征进行局部—全局学习。可靠性分数可来自多导联峰检测一致性或对小扰动的定位稳定性，先离线定义，避免靠新增大模型获得不明来源的收益。

可靠性不能仅以“像正常心拍”为标准，否则可能系统性压低 PAC/PVC 等异常心拍。必须按诊断类别报告峰检测有效率、保留心拍数和权重分布，检查异常样本是否被选择性排除。所有归一化统计由当前预训练或训练划分估计。

### 与已有文献的区别必须先写清

[HeartLang（ICLR 2025）](https://arxiv.org/abs/2502.10707) 已将心拍与节律视作词和句子，**心拍切片、token 化、加入 Transformer 本身都不是新的贡献**。其 tokenizer、预训练目标和我们拟议的可靠性机制要逐项对照。

[2026 tokenizer 对照预印本](https://arxiv.org/abs/2609.15433) 同时发现 median-beat 与 HeartLang 表示在其设置下有优势。这提醒我们保留平均/中位模板作为强对照，不能先验否定模板表示。它的单数据集结果不能直接迁移成我们协议中的预期涨点。

本项目潜在差异在于：**在峰定位不确定与少量异常心拍的条件下，验证可靠性控制如何影响形态和节律信息的独立价值**。若做不到清楚区分，收缩为表征分析工作，不声称提出全新心拍语言模型。

### 最小验证矩阵

先用固定的 TRC+噪声背景（对应 M6 的设计）研究生理分支，避免同时改变所有组件。以下均为待实现的候选配置，不是现有结果：

| 配置 | 用途 |
|---|---|
| 背景模型，无新生理分支 | 增量基线 |
| 当前平均心拍 + RR 三统计量 | 旧 Beat-RR 设计对照；新协议下需匹配运行条件 |
| 逐拍编码 + 无序均值聚合 | 区分“多看心拍”与“学习顺序” |
| 逐拍有序编码 + RR 序列，均匀有效权重 | 测试序列信息 |
| 同一序列模型 + 预定义可靠性权重 | 测试可靠性机制 |
| 同一模型，RR 在记录间置换 | 测试 RR 与记录对应关系的作用 |
| 参数与计算量匹配的固定窗表示 | 排除容量与观察窗口增加的解释 |

均值模板与中位模板先做小范围表示诊断；有实质差异再确定是否加入正式矩阵。需要时增加心拍顺序打乱对照，检查有序编码是否只是增加容量。RR 置换、顺序打乱、质量加权的其他条件保持一致。

### 主要终点与停止条件

- 在实验前选定一个原生多标签任务和 macro-AUPRC 主终点；其他域、类别、噪声或低标签指标为支持分析。不能按已见测试表现来决定任务。
- seed0 的工程与方向筛选仅用训练/验证集；先固定候选和超参，再用 {0,2,4} 做正式比较。预先定义比较族、效应阈值和校正方式，测试集按冻结方案最终评价。
- 若患者重复存在，区间估计按患者聚类；随机种子分别报告。逐记录 bootstrap 反映的是测试样本不确定性，不能代替训练随机性的估计。
- 若序列优势被容量匹配或无序聚合解释、RR 置换无影响、可靠性机制损伤干净/异常类表现，则不把对应组件写成有效新贡献。停止继续叠加损失和大范围扫权重，保留负结果。
- 只有收益、稳定性与机制对照共同支持后，才将其提升为大论文新的方法章节。

## 6. P2：导联质量感知的可变导联融合（备选）

研究问题：当部分导联不可用或被局部污染时，模型能否依据可用性与质量可靠融合，而不是固定拼接后被坏导联牵引？

先复用冻结模型做诊断：单导连续退化、导联缺失、胸/肢导联分组退化，以及退化位置和强度。先确认存在可改进的实际瓶颈，再考虑训练期 lead-aware 集合聚合或有界质量加权。

必须与旧 W7 推理期频带门控、W6 LCM、历史跨导掩码蒸馏逐项比较。不能仅换一个注意力模块就当成新机制。引入任意导联集合或重建目标前，先说明其与已关闭方案的差别；本路线图不自动重启掩码/重建训练轴。

[ST-MEM](https://arxiv.org/abs/2402.09450) 已考虑时空表示和导联组合；[K-MERL](https://aclanthology.org/2025.findings-emnlp.385/) 已采用 lead-aware 编码与动态导联 masking。后者还使用配对临床报告，我们目前没有核验相应配对数据，不能默认完整复现多模态设定。

最小比较：固定拼接、带可用掩码的简单平均、参数匹配注意力、拟议质量机制。预先固定干净性能容忍度，分别评价缺失与污染；缺失导联置零不等于真实电极错位。第一阶段保持现有 8 导联契约，扩展 12 导联须单独说明数据与模型变化。

## 7. P3：未知噪声、独立数据源与可靠性验证（配套）

优先价值在补上当前结论边界：

- **未见噪声类型**：留一类型训练/评价需新协议；现有见过全部噪声类型的 checkpoint 不能冒充留一类型模型。用冻结模型评价外部噪声源时，则明确是外部压力测试。
- **独立数据源**：先核对标签语义、预训练数据血缘和样本/患者重叠，再确定可比任务；不得默认 PhysioNet 汇集的数据互相独立。
- **开放权重基线**：优先核验 ECG-FM 等现成编码器是否适合任务，而非重训百万级基础模型。不同预训练规模、语料和架构的结果单列；与同语料同预算方法消融分开解释。
- **概率可靠性**：补充 calibration / Brier 及逐类风险；使用验证集校准。不能用不同患病率数据集的 AUPRC 直接比较模型泛化强弱。

新医院数据的验证是有价值的实证工作；但如果只有多测一个数据集，没有新问题或新方法，通常只作为验证章节。

## 8. 建议的大论文章节结构

以下为内容组织建议，不是学校格式要求：

| 章节职责 | 内容来源 |
|---|---|
| 绪论与研究现状 | 开题问题、LFBT、近期 ECG SSL 与基础模型 |
| 数据、评估与可复现基准 | 数据契约、标签语义、患者划分、原生多标签任务与统计设计 |
| 联合先验预训练方法 | 小论文 TRC / Beat-RR / 噪声框架及充分消融，注明与已发表/投稿工作的关系 |
| 新方法研究 | P1 优先，或经诊断更有依据的 P2；保留一个清晰问题与机制证据 |
| 复杂条件与外部验证 | 未知噪声、缺导/质量退化、独立数据源、校准与边界 |
| 总结与展望 | 支持了什么、失败了什么、哪些不能外推 |

若 P1 没有证据支持，先调整研究问题，不用补图、换主干或小幅调参凑新章节。也不同时启动 P1、P2 和多模态睡眠三条重线。

## 9. 建议节奏与下一项具体工作

| 阶段 | 主要产物 | 升级条件 |
|---|---|---|
| 第 1 阶段 | 多标签数据审计；HeartLang / Beat-SSL / ShapeEFM 与本项目差异表 | 数据与任务定义可复核 |
| 第 2 阶段 | 多标签 LP 基准；平均/中位/逐拍表示的验证集诊断；R 峰有效率分层 | 找到稳定瓶颈，而非仅凭设计直觉 |
| 第 3 阶段 | 选一个方法的小型 pilot 与冻结协议 | 验证集信号达到预定最小效应且干净/异常类约束满足 |
| 第 4 阶段 | 三种子正式结果、关键反事实、外部/噪声验证及新章节初稿 | 稳定增益及机制证据足够支撑主张 |

这些阶段不是计算时长承诺。实际机时取决于数据与权重是否在实验主机可用、完整协议和空闲资源。

**建议接下来先实施：原生多标签基准 + 心拍表示诊断的实验协议。** 它们能同时回答“数据任务是否可靠”和“新方法是否值得跑”，再决定 P1 是否投入完整预训练。
