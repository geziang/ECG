# 大论文实验设计：先验证信息价值，再研究新预训练

日期：2026-10-23。状态：**设计草案，未下发、未认领、未启动实验**。本文回应“如果让主机 A 执行，如何设计实验”。本轮仅编写方案与任务矩阵，不构成训练、推送、远程操作或恢复旧队列的授权。

## 1. 研究问题与已有依据

研究候选：在峰定位不稳定、少量异常心拍与多诊断记录中，怎样兼顾模板的稳定性与逐拍信息保留？目前还没有证明逐拍序列优于模板，也没有证明可靠性加权有效。

现有事实是：小论文已经完成 TRC、Beat-RR 和噪声增强联合框架；在 TRC+噪声背景上，旧 Beat-RR 的边际收益尚不明确。后续需要分别研究任务口径、表示压缩、峰定位敏感性和新预训练机制，避免同时改变所有因素。依据见[现有选线评估](THESIS_DIRECTION_ASSESSMENT_2026-10-23.md)与[小论文证据入口](../paper/PAPER_EVIDENCE_MAP_2026-10-23.md)。

## 3. 三张结果表回答不同问题

1. **本地表征的多标签开发基准**：M0/M4/M6 的冻结编码器，在同一 CPSC multihot 任务训练线性头。检验旧表征的差异；这一步不是新的方法贡献。
2. **表示方式诊断**：固定小型网络、训练划分与预算，比较匹配固定窗、平均模板、中位模板、逐拍无序集合。检验模板压缩与保留逐拍变化在该实验条件下的差别；它不是 LFBT 预训练增量实验。
3. **外部模型验证**：HeartLang 的公开预训练模型，在相同 CPSC 记录/标签划分上进行单任务 LP。保留作者原生输入要求，明确预训练规模、架构、导联与采样率差异；不与同预算消融混为一表归因。

第一批全部使用训练/验证数据。CPSC 历史测试集已经用于小论文，不宣称它是从未接触的盲测；本批不读测试信号、标签或性能，也不复用作者自动访问 test 的训练流程。官方论文测试数值的完整复现与本批验证集评价分开记录。

CPSC 本批使用记录级诊断，没有已核验的逐拍病理标注。表示对照可以检验记录分类中的信息价值，但不能直接证明某个异常心拍被平均抹去、定位到具体病理波段或评估真实峰检测精度；这些主张需要独立标注或后续专门证据。

## 4. 如何使用下载的参考源码

- **ECG tokenizer**：复用并核对切片、模板、掩码处理的实现思想，做模块行为验证。当前版本的导联默认选择、类别顺序、检测器和训练循环与本项目不同；统一适配后属于受控表示实验，不声称完整复现其论文矩阵。
- **HeartLang**：固定官方 commit，使用公开的预训练 checkpoint，先完成一个下游 LP；不重训其 tokenizer 和大规模预训练。作者启动脚本含多个标签比例与 test 路径，必须收缩到本批范围。
- **ShapeEFM**：首批只做方法差异与形态模块静态核对。若 P1 表明需要更细形态信息，再决定是否进入后续实现。
- **TolerantECG、BeatRhythm-TTA、ECG-LFM**：按所选研究问题作为备选；不并行启动三条重线。Beat-SSL、IECG 的论文可用于方法查重，不能假定已有完整训练实现。

来源：[HeartLang 固定版本](https://github.com/PKUDigitalHealth/HeartLang/tree/a08afd8117e813fee212a1ac283db4a7140a4669)、[tokenizer 固定版本](https://github.com/LeeJarvis996/ecg_tokenizer/tree/ce976cecaa27912fbba38c28fdda07abcc211b7d)。完整资料见[本地总览](../../../参考代码/论文与代码总览.md)。

## 5. P1 结果怎样决定 P2

| 观察 | 后续研究建议 |
|---|---|
| 逐拍集合相对最强简单对照在验证集有稳定优势 | 研究形态保留；下一批再区分无序集合、有序编码和 RR 序列，不把集合优势直接解释成顺序优势 |
| 中位/平均模板已经足够强，逐拍没有稳定优势 | 保留模板为强基线；考虑模板与少量局部信息互补，或暂停当前逐拍假设，不自动堆 Transformer |
| 模板/逐拍对峰位置扰动敏感，而固定窗较稳定 | 可提出峰不确定条件下的约束或融合研究；这是敏感性证据，不是实际峰检测误差率的证明 |
| 结果主要受模型容量、观察窗口、记录排除或实现差异影响 | 先修正对照；不将其当成新方法收益 |
| HeartLang 明显更强或更弱 | 如实报告并核对协议；不为维护本方法排序更改输入、样本或超参 |

草案的工程性选线门：逐拍集合相对三个简单对照中**三种子平均验证 AUPRC 最高的那一个**，平均增量至少 0.005（0.5 个百分点），且三种子增量均为正；有效类 AP 不出现预设的大幅代价。该门只用于分配后续研究预算，不是显著性检验或临床有效性门槛；实施前按任务书冻结，不能看 test 再改门槛。未过门也保留全部结果，并报告该小型网络下诊断的局限。

## 6. 正式方法阶段必须补的对照

只有新候选有训练/验证依据后，才设计正式预训练：背景模型、旧 Beat-RR、逐拍无序集合、有序形态/RR、拟议可靠性机制，以及支持具体主张所需的 RR 置换、顺序打乱、峰扰动和参数/观察范围匹配对照。每个对照对应一个主张，不预先把全部组合列成大扫描。

正式测试之前固定数据、模型、训练预算、比较族和分析代码。主指标建议 macro-AUPRC，辅以 AUROC、逐类 AP、支持数、失败/回退率及干净性能；阈值指标仅使用验证集确定阈值。若有患者重复，区间按患者聚类；没有可靠患者 ID 时说明 record-level 限制。测试样本 bootstrap 不能替代训练随机性的报告。
