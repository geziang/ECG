- 论文目标：以 A+B+C 联合框架作为核心创新对象；不追求顶刊规模，不删除任何真实的正增益，同时不夸大统计证据。

## 1. 结论先行

当前表格中 M3、M4、M6 的 CPSC 与 Chapman FT10 为“—”，原因是上一轮固定协议只安排了 PTB-XL FT10，并非运行失败或数据丢失。为使 A+B+C 论文的实验链闭合，本轮按以下顺序补实验：

1. **必须补齐** M3、M4、M6 在 CPSC、Chapman 上的 FT10，共 18 个下游训练任务。
2. **必须新增** B+C 但不含 A 的 M7，闭合 A/B/C 的完整 `2×2×2` 因子设计。
3. **必须新增** M8（A+Beat+C）与 M9（A+RR+C），回答完整框架中 Beat 和 RR 各自贡献多少。
4. **必须补做** 参数量、FLOPs/MACs、峰值显存、训练耗时、推理延迟与吞吐量，不需要重新预训练。
5. **建议补齐** N1/N2 的 seed 2、4，使“R 峰对齐必要、RR 回归作用有限”的机制结论从单种子升级为三种子证据。
6. **建议补做** 第二预训练语料上的完整 M4、CPSC 多标签敏感性分析。
7. **可选增强** 严格未知噪声类型、更多标签比例和概率校准；这些项目不阻塞当前论文投稿。

本方案不设置“表现不够好就删除实验”的淘汰门。所有合规运行都进入总账；正增益至少作为描述性结果保留，负向与零效应也同时报告。

## 2. A、B、C 的固定定义

| 组件 | 固定含义 | 实现开关 |
|---|---|---|
| A | TRC 表征校准 | `--trc 1` |
| B | R 峰对齐 Beat-RR 生理先验；包含 Beat 形态约束与 RR 回归 | `--dualview-weight 0.01 --rr-weight 0.1 --rpeak-npz ...` |
| C | NSTDB 真实噪声增强与前后半段隔离 | `--nstdb-aug 0.5 --nstdb-offset first_half` |

论文核心创新对象固定为 **A+B+C 联合框架**。其中 B 的内部组成由 M8/M9 继续拆分，避免把 Beat 与 RR 的贡献混为一谈。

## 3. “保留任何正增益”的执行规则

### 3.1. 不删除规则

1. 任一预注册比较只要点估计为正，就进入 `positive_gain_ledger.csv`，不得因置信区间跨 0、校正后不显著或只在局部任务有效而删除。
2. 不以测试结果为依据终止某个随机种子、改变权重、替换指标、改数据划分或选择性重跑。
3. 论文主表容量不足时，主表保留核心比较，其他全部放补充材料；不是从结果总账中消失。
4. 任一正增益必须与同一比较中的零效应、负向数据集、负向随机种子和计算代价共同披露。
5. 多重比较校正只改变证据等级，不抹掉原始效应量、未校正区间或方向信息。

### 3.2. 证据分层与允许措辞

| 等级 | 判据 | 论文允许措辞 |
|---|---|---|
| E1 确认性正增益 | 点估计 > 0，95% CI 不跨 0，方向稳定 | “显著提升”“稳定增益” |
| E2 稳定描述性正增益 | 点估计 > 0，至少 2/3 种子同向，但 CI 跨 0 | “观察到稳定正向趋势”“获得描述性增益” |
| E3 局部正增益 | 仅部分数据集、指标、类别、噪声或标签比例为正 | “在……条件下获得正增益”并明确范围 |
| E4 中性或负向 | 点估计 ≤ 0 或方向不稳定 | 如实报告“持平、重叠或退化”，保留在总表 |

### 3.3. “联合增益”与“协同增益”的边界

- M4 优于某个基线或单组件，可写“联合框架带来正增益”。
- 只有交互项为正时，才可写“观察到协同趋势”。
- 交互项为正且 95% CI 不跨 0、种子方向稳定时，才写“协同增益得到统计支持”。
- 若交互项不显著或为负，A+B+C 仍可作为核心**框架创新**，但表述为“联合设计、互补能力或鲁棒性扩展”，不把简单叠加写成已验证的超加性协同。

因此，核心创新对象不因某个比较未显著而放弃；调整的是证据措辞，而不是选择性删除正向结果。

## 9. 统一数据与训练协议

除被明确指定为实验因素的开关外，全部沿用 `runlog/JOINT_20261013/protocol.md`：

- NFH 预训练 100 epoch，Adam，学习率 0.001，batch size 128。
- LFBT 主目标，`lambda=0.0051`，其余既有设置冻结。
- seeds 固定为 `{0,2,4}`。
- 数据划分、患者级隔离、预处理、类别映射、验证集选模规则全部冻结。
- R 峰在无噪声原始信号上离线计算；Beat 与 RR 目标不得从加噪信号重新检测。
- RR z-score 统计量只由预训练训练集计算。
- 两个整段视图独立采噪；训练噪声使用 NSTDB 前半段，常规噪声测试使用后半段。
- 禁止根据测试结果改变权重、训练轮数或随机种子集合。
- 实现错误可修复，但必须记录修复前后 Git SHA、影响面与需要重跑的任务。

### 9.1. 正式运行前 smoke 门

每个新配置先运行 1 epoch，并满足：

1. 总损失和各启用分项有限，关闭分项为 0 或不出现。
2. `config.json` 中 A/B/C 开关、R 峰缓存和噪声 offset 与模型定义一致。
3. checkpoint 可恢复，恢复后 epoch、学习率和损失连续。
4. LP/FT 能以匹配的 `--trc` 结构加载，无意外 missing/unexpected keys。
5. 样本 ID、R 峰缓存、数据 split 哈希匹配。

smoke 失败只修实现，不看测试集指标，不改变科学协议。

## 11. 统计方案

1. 逐记录配对 bootstrap 10,000 次，多 seed 同步重采样，固定 RNG `20261015`。
2. 报告效应量、95% CI、p 值、均值±标准差、逐 seed 方向和正向 seed 数。
3. AUROC 补充 DeLong；AUPRC 以配对 bootstrap 为主。
4. 预先定义的核心比较单列；探索性多比较同时给出原始 p 与 Holm 或 FDR 校正值。
5. 校正后不显著的正效应仍进入正增益账本，但证据等级降为 E2/E3。
6. 除总体指标外保留类别级结果；类别级结果不得反向替代预先定义的总体主终点。
7. 报告绝对点数变化和相对变化，论文主文优先使用绝对百分点，避免夸大。

| 仅某域、指标、类别或标签比例为正 | 补表并在正文限定范围 | 条件性正增益 |
| 某比较为负 | 总表保留 | 明确代价与适用边界，不删除 |

完整 A+B+C 始终是论文核心研究对象；结果决定“如何表述”，不决定“是否隐去”。
