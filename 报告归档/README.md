## 证据保留原则

- 不删除原始报告、CSV、JSON、manifest、日志和 checkpoint；
- “关闭”只表示当前协议不再继续投入；
- 单 seed 结果保留为参考，但不能升级为稳定结论；
- 代码、单测、单 seed、3-seed 冻结是四种不同证据等级；
- 论文主表只能使用冻结协议、paired 结果和最终 test 评估。
