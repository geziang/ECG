# SD-LFBT 新轴方向调研（N1–N8）

> 版本：v1.1（2026-09-15：NFH/Chapman 判私有弃用，N1 改本地多库路线；MDT 弃用）
> 上游文档：《01-实验主线设计.md》（主线与推进顺序）；《02-模块调研与大实验设计.md》（D1–D10 调研与 E008 大实验）
> 本文件回答：**D1–D10 模块清单之外还有哪些方向可做、证据如何、怎么接入主线。**

## 一、为什么需要新轴

历史七轮实验（E001–E007）的全部失败都发生在**模块轴**上——往 LFBT 网络里加辅助项、轻适配器、注意力、蒸馏分支。而 D1–D10 这份清单本身也全部是模块轴的改造，其中 D6/D10/D1 重版/D2 已被内部证据否决，剩 D9/D3/D1L/D4/D7/D8 六个。

模块轴之外还有四类**从未动过的轴**：

| 轴 | 内容 | 历史覆盖情况 |
|---|---|---|
| **数据轴** | 预训练语料的规模、来源、真实性状 | ❌ 从未动过（全部实验固定在 PTB-XL folds 1-8 的 17,418 条） |
| **采样轴** | 正样本对从哪来 | ❌ 从未动过（全部是"同记录两增强"） |
| **优化轴** | 优化器与权重后处理 | ❌ 从未动过（全部 Adam + 末位权重） |
| **鲁棒/元数据轴** | 输入退化模拟、元数据监督 | ⚠️ 仅蒸馏式试过且证伪；纯增强式和元数据式未试 |

**关键性质：新轴与模块轴正交。** 模块轴的负结果不覆盖新轴；新轴可以叠加在任意主线配置上。

## 二、新轴方向逐项调研

> 每项含：做什么 → 假设 → 外部证据 → 为什么未被内部负结果覆盖 → 成本与实现入口 → 风险与对策 → 粗筛判据 → 定位。

### N1 多库联合预训练（数据轴）🟢 底座级，几乎必做

- **做什么**：预训练语料从 PTB-XL folds 1-8（17,418 条）扩展为**本地多库混合语料**（≈38,700 条，零下载）；下游评估协议不变。**NFH/Chapman 判定为私有数据集，2026-09-15 起弃用**。本地可用构成（已清点 `E:\数据集` Challenge2020）：

  | 库 | 条数 | 采样率 | 入预训练 | 备注 |
  |---|---:|---|---|---|
  | PTB-XL folds 1–8 | 17,418 | 500Hz | ✅ | 冻结协议主体；folds 9/10 留下游 |
  | CPSC 2018 + extra | 10,330 | 500Hz | ✅（仅下游 train 患者） | E5-4 跨库评估库；防泄漏见《04》 |
  | Georgia | 10,344 | 1000Hz | ✅ | 可选第三下游库（SNOMED 标签） |
  | PTB / INCART | 516 / 74 | 1000/257Hz | ✅ | 小库顺带入语料 |
  | Challenge2020 的 ptb-xl 份 | 21,837 | 500Hz | ❌ 禁用 | 与下游评估同源，防泄漏 |
- **假设**：SSL 表征质量随语料规模与设备多样性增长。当前协议最大的短板可能不是模型而是语料——论文用 NFH 43,994 条，我们只有它的 40%；本地多库拼到 ≈3.87 万条（论文的 88%），并额外带来跨设备/跨地区多样性。
- **外部证据**：LFBT 论文本身（Table 2 语料设定）；ECG 基础模型普遍规律（NEJM AI、ECG-LFM 依赖大规模语料）；跨设备多样性改善泛化是共识。
- **未被覆盖**：E001–E007 全部固定同一语料，数据轴零历史。
- **成本与入口**：数据工程为主，**全部本地、零下载**（wfdb 读取 → 500Hz 重采样 → 取 8 导联 [II,III,V1–V6] → 10s 窗 2048 点 → z-score → 去多标签记录）；复用 `preprocess_ptbxl.py` 流程改写，CPSC 部分参考源仓库 `prepare_cpsc.py`；训练成本 = 一次预训练。
- **风险与对策**：跨库采样率/增益差异 → 统一重采样 + 逐导联 z-score 已覆盖；跨库类别分布不同 → 预训练无标签，不受影响；CPSC 变长记录（6–60s）→ 下游取中心 10s 窗、预训练取随机 10s 窗；语料替换导致与历史 B0 不可比 → 走并行"语料轨"（见第四节接入方式）。
- **粗筛判据**：PTB-XL 下游 LP/FT 不低于当前 B0（语料升级不允许掉点）+ 跨库迁移（E5-4）显著改善。
- **定位**：**Phase 0 底座工作**。它和 D9 一样属于"把地基打对"，且直接弥补"1.7 万条替代 4.4 万条"这一最大协议短板。

### N2 合成数据预训练/增广（数据轴）🟢 冲点 + 机理故事

- **做什么**：用 ECG 仿真器（ECGSYN 类动力学模型）生成参数可控的合成信号（心率、电轴、ST 偏移、噪声水平可指定）。两种用法：a) **混合增广**——按比例（10% 起步）混入预训练批次；b) **真实↔合成跨域对比**——构造跨域正样本对。
- **假设**：合成信号提供无限、参数已知的"免费监督"，补足稀有形态覆盖（罕见 ST 形态、极端心率），跨域对比迫使模型学不变表征。
- **外部证据**：[SimECG（OpenReview）](https://openreview.net/forum?id=gUXKz2PwQb)——合成数据预训练匹敌真实数据预训练，26 个下游任务平均 +5.49% F1。
- **未被覆盖**：数据轴零历史；与 E003"跨领域模块"不同族（那是网络模块，这是数据来源）。
- **成本与入口**：S–M。仿真器 CPU 生成、离线入库，训练侧只需数据加载器支持多来源。
- **风险与对策**：域差过大 → 合成占比从 10% 起步扫描；仿真信号过于规则、模型学到伪特征 → 生成时注入 HRV 变异与噪声。
- **粗筛判据**：混合预训练下 LP 不掉点，且少标签场景（FT10）改善优先看。
- **定位**：冲点/故事线。**额外价值**：合成信号的参数已知（电轴/ST 程度），天然支撑机理归因分析（按参数分组的表征分析图），这是真实数据给不了的。

### N3 患者级正样本对（采样轴）🟢 低成本增广

- **做什么**：正样本对来源从"同记录两增强"扩展为"同患者不同记录"。实现上是采样器改动：数据集按 `patient_id` 重组索引，batch 内同患者的不同记录互为附加正对。
- **假设**：同患者的不同记录共享个体特异因素（基底节律、电轴、传导特性），是比"同记录两增强"更强的不变性监督。
- **外部证据**：PTB-XL 结构上 21,837 条记录 / 18,885 名患者（[Sci. Rep. 2025](https://www.nature.com/articles/s41598-025-90084-2)等确认），约 15% 记录来自复诊患者；患者级策略是新兴方向、未饱和。
- **未被覆盖**：视图层历史上只试过增强（RRC-TO 变体）和蒸馏（E005），从未动过**采样结构**。
- **成本与入口**：S。改 `ECGDatasetFolder` 的索引组织与 `MultiViewDataInjector` 的配对逻辑；ptbxl.csv 自带 `patient_id`。
- **风险与对策**：同患者跨日病情变化引入假正对 → 过滤条件加"同 superclass 标签"；复诊患者占比有限 → 作为**附加**正对来源，不替代原增强对。
- **粗筛判据**：LP Δ≥1.0pt 过粗筛线；机制指标——按患者检索的表征聚类质量（同患者表征 top-1 召回）。
- **定位**：低成本增广，可叠加在任意主线配置上（与 D9/D3/D7 均正交）。

### N4 权重 EMA / model soup（优化轴）🟢 免费附件，默认全开

- **做什么**：预训练后期（如最后 50 epoch）对 encoder 权重维持指数滑动平均（EMA），下游加载平均后权重；或多 checkpoint 均匀平均（soup）。
- **假设**：SSL 损失面波动大，末段权重在极小值间震荡；平均后落在平坦盆地中心，表征更稳。
- **外部证据**：MoCo v3 的 latest weight averaging、SWA/model soup 在 SSL 与泛化场景的普遍正结果。
- **未被覆盖（关键区分）**：E005 证伪的是**师生蒸馏**（额外的蒸馏损失分支、独立教师网络）；N4 不改损失、不加分支、无教师，纯粹是权重后处理——机制完全不同。
- **成本与入口**：近零。训练循环多维护一份 EMA 状态字典；注意与 BN 的交互（若 D9 已换 LN 则无此问题）。
- **粗筛判据**：不设门槛——所有确认配置默认附带，报告 with/without 两行，正则赚、负则关。
- **定位**：免费附件。

### N5 SAM / F-SAM 优化器（优化轴）🟡 第三梯队

- **做什么**：预训练优化器从 Adam 换为 SAM（锐度感知最小化）或其 SSL 稳定变体 F-SAM。
- **外部证据**：[SAM（Foret et al.）](https://arxiv.org/abs/2010.01412)2800+ 引用；[F-SAM（CVPR 2024）](https://cvpr.thecvf.com/virtual/2024/poster/29933)专门解决 SSL/大 batch 场景的训练稳定性；[SSAM（JMLR 2025）](https://www.jmlr.org/papers/v26/24-0065.html)解决步长不稳定。
- **风险**：训练时间 ×2（两次前向反传）；[ICML 2026 有批评](https://icml.cc/virtual/2026/poster/66010)指出 SAM 在扰动参数下可能"虚报"好性能 → 必须用与主线完全一致的标准协议验证。
- **粗筛判据**：同协议下 LP Δ≥1.0pt 且训练曲线无异常。
- **定位**：第三梯队/附录冲点，主线定型后再试。

### N6 多层辅助 BT 损失（表征深度轴）🟡 D9 的延伸项

- **做什么**：在 projector 第一/第二层输出各加辅助 BT 损失（权重递减），总损失 = 末端 + 中间层加权和。
- **假设**：深层 projector 吸收了全部不变性压力，encoder 输出（LP 直接读的地方）欠正则；中间层辅助损失把正则压力前移。
- **外部证据**：多投影头/多层正则在 SimSiam、VICReg 变体与 MGP 类工作中有先例。
- **未被覆盖**：损失层历史只试过加新损失项（辅助对齐、蒸馏），从未做过**层间分布**改造。
- **成本与入口**：S。projector 前向时缓存中间输出即可。
- **粗筛判据**：LP Δ≥1.0pt（LP 是主要受益范式）。
- **定位**：D9 的同插槽递进——D9 定版后在其上扫，不单独排队。

### N7 导联丢弃一致性增强（鲁棒轴）🟢 并入 D8

- **做什么**：两视图中随机将 k∈{1,2} 个导联置零（其余增强照常），靠跨视图一致性学导联子集稳定表征。**无蒸馏、无教师、同一网络**。
- **假设**：导联脱落/缺失是真实部署最常见的输入退化；增强式一致性让表征对"看到哪些导联"稳定。
- **外部证据**：缺失导联 ECG 建模是活跃方向；E5-1 的 37 条件导联缺失评估管线（E007 T6）现成可复用。
- **未被覆盖（关键区分 + 未关闭线索）**：E005 证伪的是师生蒸馏框架下的掩码（完整教师→受损学生）；N7 是纯增强一致性，无教师。另外 **E002 的 Lead Mask 是全档案唯一"待复验"就被搁置的线索——严格说它从未被证伪**。
- **成本与入口**：S–M。在 `augmentations.py` 加 LeadDropout 变换。
- **粗筛判据**：干净库回落 ≤0.3pt 且 37 条件缺失均值显著优于 B0（复用 E007 T6 管线出表）。
- **定位**：并入 D8（S5 步），合并为"真实世界退化防御"故事（噪声 + 缺失导联 + 电极错位三线）。

### N8 元数据辅助头（元数据轴）🟡 附录/防御

- **做什么**：预训练时加 age/sex 小回归头（PTB-XL 的 ptbxl.csv 自带），辅助损失权重小。
- **外部证据**：ECG 基础模型（如 [NEJM AI](https://ai.nejm.org/doi/abs/10.1056/AIoa2500164) 类）用生理元数据辅助预训练有先例；年龄回归是 ECG 表征质量的老牌代理任务。
- **代价**：不再是"纯 SSL" → 论文定位须写成"元数据正则化 SSL"，创新叙事弱化。
- **粗筛判据**：LP Δ≥1.0pt 且不伤 FT。
- **定位**：附录/审稿防御，不进主线。

## 三、明确不开的方向（预先排除，避免再走弯路）

| 方向 | 排除理由 |
|---|---|
| ECG-文本跨模态（CLIP 式） | 本地无报告文本数据；单卡 4090 算力不够；[ECG-语言预训练](https://icml.cc/virtual/2025/poster/44523)已有大资源工作占位 |
| 换更大 backbone 的 scaling study | 算力与新颖性双输；[ECG-LFM（Nat. Comm. 2026）](https://www.nature.com/articles/s41467-026-72436-2)已用千万级语料封顶这条线 |
| 聚类/原型/师生蒸馏族 | E005 证伪 + D10 已弃，不再回头 |
| NFH/Chapman 语料扩展 | 判定为私有数据集（2026-09-15），不可得；N1 改本地多库路线 |
| MDT_DATA（2GB 私有格式 Holter） | 判定无用数据集，弃用 |

## 四、接入方式与优先级总表

### 4.1 语料轨并行（解决 N1 与历史可比性的冲突）

```text
模块轨（主线，语料冻结在 PTB-XL folds1-8）      语料轨（并行）
────────────────────────────────────      ────────────────────────────
S0 B0 基线（✅）                            N1-0 多库数据准备（本地清洗/入库，零下载）
S1 +D9  …                                  N1-1 多库预训练 + 原版 LFBT 目标
S2 +D3  …                                   ↓ 判据：PTB-XL 下游 ≥ B0 且跨库改善
S3 +D4  …                                  通过 → 累加矩阵（G2/S2 起）切换到 N1 语料
                                              不通过 → 主线保持 PTB-XL 语料，N1 归档
```

两轨在 G2 累加阶段合流；G1 阶段所有模块粗筛仍在 PTB-XL 语料上做，保证与 E001–E007 历史可比。

### 4.2 优先级总表

| 优先级 | 方向 | 接入点 | 成本 |
|---|---|---|---|
| **P0（底座级）** | N1 多库预训练 | 语料轨并行，G2 前定版 | 本地数据工程（零下载）+ 1 次预训练 |
| **P0（免费）** | N4 权重 EMA | 所有确认配置默认附带，报 with/without | 近零 |
| **P1（增广）** | N3 患者级正样本 | 挂在 D9 底座上粗筛（改动只在采样器） | S |
| **P1（故事）** | N2 合成数据 | D7 冲点同期做，支撑机理归因图 | S–M |
| **P1（并入）** | N7 导联丢弃 | 并入 D8（S5 步）合并鲁棒故事 | S–M |
| **P2（梯队）** | N5 SAM、N6 多层损失、N8 元数据 | 主线定型后按序试，各自带停止规则 | S–M |

### 4.3 新轴与现有主线的正交性核对

| | D9 | D3/D1L | D4 | D7 | D8 |
|---|---|---|---|---|---|
| N1 语料 | ✅ 正交 | ✅ | ✅ | ✅ | ✅（且互相成就：多库→跨库鲁棒故事） |
| N2 合成 | ✅ | ✅ | ✅ | ✅（合成+MIM 天然配） | ✅（合成可控噪声） |
| N3 患者对 | ✅（都在 batch 内统计） | ⚠️ 与 D3 需查 c 头患者一致性 | ✅ | ✅ | ✅ |
| N4 权重EMA | ✅（D9 换 LN 后更干净） | ✅ | ✅ | ✅ | ✅ |
| N7 导联丢弃 | ✅ | ⚠️ 与 D3 联动需设计（置零导联的 s 头如何处理） | ✅ | ✅ | 同插槽合并 |

⚠️ 两处需要专门设计的地方（N3×D3、N7×D3），在对应模块进入确认阶段前给出实现说明即可，不阻塞当前启动。
