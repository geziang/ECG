# 下周多导联 ECG 自监督学习科研与代码任务书

**版本**：2026-09-19  
**仓库**：`https://github.com/geziang/ECG.git`  
**代码根目录**：`ECG_SSL_LFBT-main/`  
**适用机器**：A（RTX 4090 24 GB）、B（RTX 3080 10 GB）  
**目标**：用一周时间完成一次可复核、可写作、能区分机制的实验，而不是继续堆叠零散模块。

## 一、先给执行结论

下周只保留三条主线：

1. **A 线：解剖区域关系目标**。实现 ACL-ECG 的完整机制作为受控对照，并单独修复 D1L。重点不是声称“首次做解剖感知 ECG SSL”，而是回答：在 LFBT 的导联级表征中，四区域 projector 和跨区域同记录正对是否比简单的组内拉近更有效。
2. **B 线：心动周期感知重建**。先回收旧 D7，再比较普通连续遮挡、多片段遮挡和 CCM 周期内遮挡。重点是判断“生理相位保真的局部重建”是否比任意长缺口更适合少标签和缺导联场景。
3. **C 线：外部 NFH 预训练协议**。建立 Ningbo/NFH 外部锚点，回答当前结果究竟是 ECG 表征，还是 PTB-XL 目标域统计。NFH 预训练本身不是新算法，而是解决论文可比性和跨域泛化可信度的必要实验。

**如果只能押一个方法方向**：押 A3（四区域、独立 projector、区域内/跨区域双 InfoNCE 的受控实现）。  
**如果只追求一周内最容易得到正信号**：押 B2（CCM 周期遮挡 + 轻量重建）。  
**无论哪条线成功，C1 外部 NFH 锚点都必须完成或至少完成数据审计和预训练启动。**

下周不再优先投入：注意力/ECA、Mixer/GAT、EMA、患者正对、VICReg 直接替换、Sinc、MixUp、HRV、多库无域适配乱混、师生蒸馏。它们的当前实现已经给出足够的关闭信号，继续扫描只会增加多重比较和归因困难。

## 二、历史实验点评：哪些结论成立，哪些必须改写

### 2.1 B0 已成立，但不是论文的严格复现

当前 B0 使用 PTB-XL folds 1–8 预训练（约 17,418 条），下游仍是 PTB-XL 官方 folds 9/10 体系；LP AUPRC 约 0.7177，多 seed 约 0.7137±0.0036。这个结果证明代码链路、损失下降和下游迁移是通的，但不能写成“超过论文 LFBT”。

原论文使用 NFH/SNPH 外部预训练后迁移到 PTB-XL、CPSC 和 Chapman；论文 PTB-XL LP AUPRC 为 0.6923，FT AUPRC 为 0.7257。数据源、预处理、下游样本数和训练协议不同，绝对数值不能直接排名。下周 C1 的意义就是补上这个协议缺口。

### 2.2 数据体系 B 必须永久弃用

历史审计发现旧的 `data/downstream` 体系存在患者跨 split、重复文件名和 train/test 交叉污染，其中报告记录了 177 条 train/test 交叉污染。后续只使用 `data/ptbxl`、官方 `strat_fold`、患者隔离 manifest 和版本化预处理。所有旧体系结果只能作为工程排错记录，不能再作为论文主结果。

### 2.3 TRC/GRN 是唯一值得保留的正向基座，但主张要收紧

TRC 在 FT10 新批次中约 +0.97pt，3/3 seed 同号；早期批次在 FT10 约 +1.1pt，缺导场景约 +2.8～3.1pt。它最适合定位为“少标签和导联缺失下的候选适配器”。

不能写成“所有场景稳定提升”：新批次 FT100 约 −0.16pt，缺导结果部分来自单 seed，完整导联本身也有提升。下周 TRC 只作为预注册 comparator，不能在 A/B/C 首轮同时叠加，以免把新机制和已有正向模块混成不可归因的组合。

### 2.4 可以关闭的历史方向

| 方向 | 证据 | 下周处置 |
|---|---|---|
| 注意力、ECA、导联加权、Mean 融合 | 多个变体无稳定提升 | 关闭 |
| Mixer/GAT/自动复合 | 明显退化或复合后过拟合 | 关闭 |
| 师生跨导联蒸馏 | clean 约 −2.3pt，缺导也未改善 | 关闭；不能外推到 MAE |
| LGA 组内拉近 | FT100 约 −0.89pt，配对区间全负 | 关闭“硬拉近”实现 |
| N1 五库无域适配混合 | LP 约 −3.07pt | 关闭“直接乱混”；不否定单一外部库 |
| EMA、Sinc、MixUp、HRV、患者正对 | 当前协议下均为负 | 关闭当前实现和权重 |
| VICReg 六种直接替换 | 约 −1.3 到 −10.7pt | 关闭直接替换；不写成 VICReg 全族失败 |

### 2.5 必须撤回或降级的结论

**D1L 旧负结果必须撤回。** 当前代码把生理目标 τ 放在 `off_diagonal(c)`，主动制造投影维度间的交叉协方差；LFBT 的正确语义是 correlation diagonal 负责跨视图同坐标对齐，off-diagonal 负责去冗余。旧的 −0.60pt 只能说明错误实现有害，不能证伪结构化目标。

**D9 负结果不能解释为 batch=128 不适合 VICReg。** 原论文 Table 6 的 PTB-XL batch=128 是其表格中的最佳点之一。当前 D9 还把不同导联 projector 的 raw outputs 直接 MSE 拉近，任务定义本身不标准。

**D7 不是失败。** 当前矩阵没有 D7 的完整结果行，旧实现还是单段 50% mask、只 mask view1、输入波形重建。它只能标记为“未验证且任务可能过难”。

**E006 P1/S1 是弱正、基座依赖。** 它在 AR-B3 上有弱正信号，在 B0 上没有；只能作为“鲁棒基座可能改变先验收益”的线索。

### 2.6 我们为什么暂时做不出来，而别人能做出来

根因不是单个网络模块，而是以下五件事叠加：

1. **数据协议不一致**：别人使用外部医院数据预训练，我们主要做了目标域同分布预训练。
2. **复制了模块名，没有复制完整机制**：LGA 的三组均值和轻 BT 不是 ACL-ECG 的四区 concat、独立 projector 和双层 InfoNCE。
3. **目标位置有实现错误**：D1L 的 τ 放错矩阵位置。
4. **强基线附近的信号小于 seed 方差**：B0 seed 差异约 0.8pt，单 seed +0.2～0.4pt 不足以支持改进。
5. **筛选阶段复用了 test**：候选用 test 晋级，再报告 test，会把偶然波动转成方法结论。

下周的实验设计必须让这五个因素分别可检验，而不是继续用一个最终分数猜原因。

## 三、方向 A：解剖区域关系目标

### 3.1 科学问题

哪些导联关系应该共享，哪些关系应该保留特异性？“同组导联硬拉近”是否错误，而“同一记录跨区域保持一致、不同记录保持可分”是否更合理？

ACL-ECG 论文的 Eq. (11) 要特别准确地实现：`d != d'` 表示同一 ECG 的两个区域跨视图仍是正样本，批内其他 ECG 是负样本；它不是把不同区域互相推远。论文 PTB-XL LP 报告为 AUROC 0.9145±0.0031、AUPRC 0.7122±0.0049。

### 3.2 最小实验矩阵

| 编号 | 配置 | 目的 |
|---|---|---|
| A0 | 本机 B0 | paired anchor |
| A1 | D1L-fix：PSD 目标矩阵，II-III=.5、相邻胸导=.2 | 翻案验证 |
| A2 | 四区 + 独立 projector + 仅区域内 InfoNCE | 检验区域一致性 |
| A3 | A2 + 跨区域 Eq. (11)，γ=.5 | 首押配置 |
| A4 | A3 的随机四区分组 NEG | 证明收益来自解剖结构，而非参数量 |

四区固定为：`(II,III) / (V1,V2) / (V3,V4) / (V5,V6)`。区域输入由两个导联特征 concat 后进入各自 projector；不要再做三组均值后直接 BT。A3 是区域目标的替换式实现，不能同时把旧 LGA 作为额外拉近项叠加进去。

D1L-fix 的目标矩阵必须满足：对称、对角为 1、特征值不低于 `-1e-6`。关闭 D1L 时必须与 B0 逐位一致；`tau=1` 的全矩阵只作为闭合基线检查，不能改变默认路径。

### 3.3 成功、失败和止损判据

- 1-seed val paired ΔAUPRC ≥ +0.5pt，且 AUROC 不下降超过 0.2pt，才进入 3-seed。
- A3 必须优于 A2，且真实分组不能被随机分组稳定超过。
- 若 A3 只复现 ACL-ECG 数字，不超过 B0，不写成新 SOTA；写成“受控复现与机制对照”。
- 若 A3 与随机分组相同，关闭区域线，不继续堆 TRC/D7。
- common/specific 解耦只在 A3 有正向或结构诊断需要时启动，不能作为首轮盲加模块。

### 3.4 主要风险

ACL-ECG 已经发表，解剖分区本身不是新颖点。我们的可写贡献必须来自：LFBT 兼容的区域目标、D1L 的 PSD/对角目标修正、与简单 BT/LGA/随机分组的受控比较，以及跨域和缺导联评价。

## 四、方向 B：心动周期感知重建

### 4.1 科学问题

生理相位保真的局部遮挡，是否比任意长连续遮挡更能学习可迁移的形态？

### 4.2 最小实验矩阵

| 编号 | 配置 | 目的 |
|---|---|---|
| B0 | 无重建 | paired anchor |
| B1 | 旧 D7：单段 50%，view1，波形 MSE | 归档审计，不作主张 |
| B2 | 多片段总遮挡约 20%，两视图独立，masked MSE | 任务难度对照 |
| B3 | CCM：每个 RR 周期内遮挡约 20%，不跨 R 峰，两视图独立 | 首选生理方案 |
| B4 | B3 + lead-wise dropout | 仅 B3 正向后做缺导测试 |

R 峰优先用 V5 离线检测并缓存；检测失败时回退到 B2 的多片段 mask。重建 target 是原波形，不引入 teacher，不把它和 E005 蒸馏混为一类。重建损失按 masked 点归一，`eta` 根据末轮 `L_rec/L_BT` 标定到辅助梯度约 5%～10%。

### 4.3 必须记录的诊断量

- R 峰检测成功率、mask 是否跨 R 峰；
- `L_rec/L_BT` 和两路梯度范数；
- clean LP、FT10、37 条件缺导；
- 正常节律、AF、PVC 等病种/节律分层；
- 两视图 mask 是否独立、是否同步跨导联。

若重建梯度长期超过 BT 的 20%～30%，或 val 相对 B0 下降超过 0.5～1.0pt，立即停止该配置。B3 仍为负时，不增加 decoder 复杂度，关闭波形重建线，后续再考虑 latent prediction。

### 4.4 参考文献

MAE-ECG、ST-MEM、CREMA、CoRe-ECG 都支持“混合对比/重建”值得研究，但它们也说明普通跨导联 raw MSE 容易被导联线性关系投机。下周只做轻量、可诊断的版本，不宣称新 MAE。

## 五、方向 C：外部 NFH 预训练和跨域泛化

### 5.1 科学问题

真正外部医院预训练是否能改善 PTB-XL、CPSC、Chapman 的迁移和缺导联稳定性？

### 5.2 最小实验矩阵

| 编号 | 配置 | 目的 |
|---|---|---|
| C0 | 当前 PTB-XL B0 | 同域基准 |
| C1 | Ningbo/NFH-only，匹配 optimizer updates | 外部 B0' |
| C2 | C1 + TRC | 检查已有适配器跨域稳定性 |
| C3 | C1 → PTB-XL/CPSC/Chapman | 跨库迁移 |

NFH 公开子集约 34,905 条；ACL-ECG 清洗后使用 33,403 条。不能把公开子集数量和原 LFBT 论文的 43,994 条硬拼。首轮 NFH 训练应按 optimizer updates 与 PTB B0 匹配，避免数据量翻倍造成暴露次数差异。

预处理必须记录导联映射、采样率、有效长度、归一化、异常记录、SHA256 和患者重复检查。预训练不能混入 CPSC/Chapman 测试数据。C1 即使不超过 B0，也能形成协议和泛化结果；但不能把它包装成新算法。

### 5.3 外部评估

至少报告 PTB-XL LP/FT10、CPSC LP、Chapman LP、完整导联和 37 条件缺导曲线。缺导评估包括 8 个单导、随机双导、II+III、胸导组合；明确这是“导联置零”，不是电极物理错位。

如果 NFH 数据审计周三前未完成，暂停 C2/C3，改做 PTB→Chapman 外部测试；不要重新启动 N1 多库乱混。

## 六、双机一周计划

### 周一：协议闸门

**A 机**：NFH 下载、清洗、manifest、预训练启动；完成 A1/A2 代码框架。  
**B 机**：本机 B0 anchor；D1L-fix 单测；回收 D7 checkpoint；5 epoch smoke。

交付：两机 B0、NFH manifest、预处理哈希、D1L 数值回归报告、D7 是否已训练/仅漏评估的结论。

### 周二：A 线粗筛

**A 机**：NFH 继续训练；A2/A3 1-seed 预训练。  
**B 机**：A1 D1L-fix、A4 随机分组 NEG；同步跑 LP/FT10 val。

### 周三：B 线和外部锚点

**A 机**：完成 C1，先跑 PTB-XL LP，再跑 CPSC/Chapman。  
**B 机**：B1、B2、B3 1-seed；检查 R 峰缓存、mask 比例和梯度比。

### 周四：候选确认

只保留 val 配对增益达到门槛的配置，跑 3 个 paired seeds。不要查看 test 来决定是否继续。

### 周五：跨库和鲁棒性

对 A 线优胜者和 C1 做 PTB-XL/CPSC/Chapman、FT10、完整/缺导/SNR 评估。TRC 作为单独 comparator，不和所有候选同时组合。

### 周六：冻结

冻结代码 SHA、数据 manifest、超参数和 checkpoint。每个最终配置只评一次 test，计算 patient-level bootstrap 或 permutation 区间。

### 周日：归档和写作材料

生成主结果表、消融表、失败表、训练曲线、缺导热图、数据流程图和“协议差异说明”。所有结论分为：确认、趋势、未验证、关闭。

## 八、统一统计纪律和止损线

1. 每台机器先跑本机 B0 anchor，绝对 AUPRC 不跨机器比较。
2. 所有候选先 5～50 epoch smoke，再决定是否 200 epoch。
3. 只用 val 选 checkpoint 和候选；test 最终冻结后只评一次。
4. 1-seed val ΔAUPRC < −0.5pt，直接停止；≥ +0.5pt 才进入 3-seed。
5. 3 seed 同号是“可复现趋势”，不是自动显著。
6. A3 若不优于 A2，或真实分组不优于随机分组，关闭区域线。
7. B3 若仍负，不继续增加 decoder 复杂度。
8. C1 若数据审计不过关，暂停外部组合，不把协议问题误写成模型失败。
9. 所有负结果保留原始日志、配置和 checkpoint，不删除、不改写为“未运行”。
