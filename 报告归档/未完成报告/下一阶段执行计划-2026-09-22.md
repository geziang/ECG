## 二、优先级：只做一条主实验线

### P0：先核对并冻结评估账本

1. 确认当前运行进程是否仍在执行；如果没有结果文件，不把“队列启动”写成“实验完成”。
2. 检查 `runlog/W1/c2_chain.py`、`runlog/W1/c3_evals.csv` 的 `lp/ft10` 标签是否一致。
3. 每个 checkpoint 记录：git SHA、checkpoint SHA、数据 manifest、seed、optimizer updates、TRC 开关。
4. 只允许 validation 选点；test 在配置和 checkpoint 冻结后评一次。

### P1：完成 C1/C2 三 seed paired confirmation

使用 `runlog/W2/confirm_matrix.py`，优先顺序固定为：

1. CPSC LP：C1/C2，seed `0/2/4`；
2. PTB-XL FT10：C1/C2，seed `0/2/4`；
3. PTB-XL LP：作为基线和域差补充；
4. Chapman LP：最后做，因为存在 NFH/Chapman 数据血缘疑虑；
5. 缺导：只评 C2 相对 C1 最关键的单导和双导条件。

每一项都记录 paired delta，而不是只记录绝对 AUPRC。

### P1.5：复用冻结 checkpoint 做低成本鲁棒补强

这一步不新增预训练模型，避免把“训练目标收益”和“输入退化收益”混在一起：

1. 对 B0/C1/C2 冻结 checkpoint 做 baseline-wander、肌电噪声、50/60 Hz 工频噪声，SNR 取 `0/5/10/20 dB`；
2. 增加连续导联质量衰减和真实 test-time adjacent lead-swap 评估，明确区别于已有的导联置零；
3. 复用冻结 encoder 补 PTB-XL FT20/FT40，输出 AUPRC、Macro-F1、per-class AP、Sensitivity、Specificity 和 calibration；
4. 将结果汇总为一张“clean—噪声—缺导—标签效率”鲁棒基准表，作为论文结果章或限制说明，不在此阶段引入新损失。

### P2：按预注册门槛做一次判决

| 轴 | 晋级标准 | 失败后的写法 |
|---|---|---|
| CPSC LP | 3/3 seeds 相对 C1 同号，均值至少 `+0.5 pt` | C2 为单 seed 趋势或关闭 |
| PTB FT10 | 至少 2/3 同号，均值至少 `+0.5 pt` | 不支持标签效率主张 |
| 缺导 | clean 不升但相对掉幅稳定更小 | 只能称“鲁棒性适配器” |
| Chapman | 仅作为血缘域补充，不单独决定主方法 | 不写跨医院泛化 |

### P3：决定论文落点

- **方法论文**：C2 在 CPSC/FT10/缺导至少一个核心轴稳定通过门槛，且没有明显 clean 退化；
- **协议实证论文**：C2 不稳定，但 B0/C1/C2 的数据血缘模式、失败方向和实验纪律可复核。

两种情况都不需要再添加新模块。

## 三、B 线 CCM 的处理建议

CCM 目前不是主论文必需项。建议在 C1/C2 结果冻结前不再占用主要 GPU 资源；只有出现以下情况之一才运行：

- C2 不通过，但需要一个机制明确的辅助线；
- 需要补一组少标签/缺导的重建对照；
- 论文主线选择“协议与失败分析”，CCM 可作为受控负对照。

若运行，严格按 B1/B2/B3 最小矩阵，只做 5 epoch smoke 后单 seed full；同时记录 R 峰成功率、fallback 比例、`L_rec/L_BT` 和重建梯度比。不要再增加 decoder、teacher 或跨导联 raw MSE。

## 四、明确停止的新实验

在 C2 判决完成前，停止：

- Attention/ECA/Mixer/JEPA；
- 新的 D1L/ACL/LGA 变体；
- VICReg、EMA、Sinc、MixUp、HRV、患者正对；
- 无域适配的多库混合预训练；
- 单纯调 gamma/lambda、projector、pooling、裁剪比例。

这些方向已有足够的关闭证据，继续跑只会增加多重比较和叙事噪声。
