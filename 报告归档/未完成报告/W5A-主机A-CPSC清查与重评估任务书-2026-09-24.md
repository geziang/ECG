## A-1 CPSC 测试集口径审计（必做，先做，结果决定是否触发 A-2）

**背景**：W4 逐记录预测产物实测 CPSC 测试集 **2,004 条**（y_true.npy 文件头核实），但 `runlog/W1/cpsc_manifest.json` 类计数合计 **1,385 条**；其中 NSR/AF/PVC 三类与混淆矩阵行和完全吻合，其余六类约 1.7 倍。怀疑早期一版预处理（疑似多标签记录重复写入多个类目录）残留文件未被清理，现行 `prepare_cpsc_chapman.py` 写入前不清空目录、manifest 只计新写入。

在仓库根目录（`runlog/` 所在处）执行并**完整保留输出**：

```powershell
# 1. 三个 split 的总数（test 预期暴露 2004；train/val 顺带查）
(Get-ChildItem data\cpsc\test  -Recurse -Filter *.npy).Count
(Get-ChildItem data\cpsc\train -Recurse -Filter *.npy).Count
(Get-ChildItem data\cpsc\val   -Recurse -Filter *.npy).Count

# 2. test 分类计数（对照 W1 manifest：NSR185 AF245 IAVB138 LBBB39 RBBB309 PAC121 PVC135 STD168 STE45，合计1385）
Get-ChildItem data\cpsc\test -Directory | ForEach-Object { "{0} {1}" -f $_.Name, (Get-ChildItem $_.FullName -Filter *.npy).Count }

# 3. 跨类重复 stem（同一记录写入多个类目录 → 直接证据）
Get-ChildItem data\cpsc\test -Recurse -Filter *.npy | Group-Object Name | Where-Object Count -gt 1 | ForEach-Object { $_.Name }

# 4. 时间戳分层（区分新旧两批 prep）
Get-ChildItem data\cpsc\test -Recurse -Filter *.npy | Group-Object { $_.LastWriteTime.ToString("yyyy-MM-dd HH") } | Sort-Object Name | Format-Table Name,Count
```

**判定规则**：

| 观察 | 判定 | 动作 |
|---|---|---|
| test 总数 ≈2004，重复 stem >0 或时间戳成两批 | **残留/重复** → 触发 A-2 | 写 `runlog/W5/cpsc_audit.md`（现象+四条命令输出+判定），继续 A-2 |
| test 总数 =1385 且无重复 | 与预测产物矛盾（loader 应另查） | **停**，把输出推上来等办公机判定，勿自行重跑 |
| 其他中间态（如总数既非1385非2004） | 异常 | **停**，写报告上推 |

**顺手确认（不触发动作）**：Chapman 实测 2,047 = manifest 合计 ✓、PTB 1,739 = fold 10 ✓，只记录不需查；若想稳妥可各跑一条总数命令记入审计文件。

## A-2 CPSC 重评估链（仅当 A-1 判定"残留/重复"）

### A-2.1 重建数据目录

1. 旧目录**改名备份，不删除**：`Rename-Item data\cpsc data\cpsc_bak_2004`
2. 重跑预处理（参数与 W1 首次运行一致；源数据 `F:\数据集\...challenge-2020-1.0.2\training\cpsc_2018\g*\*.hea` 不动）：
   `python prepare_cpsc_chapman.py --which cpsc ...`
   **manifest 输出指向 `runlog/W5/`**（命名如 `cpsc_manifest_v2.json`），W1 的 manifest 只读不变。
3. 自检：新 test 总数应等于新 manifest 类计数合计（预期 ≈1,385）；train/val 同样核对。

### A-2.2 重出 CPSC LP（15 跑 = 5 配置 × seeds {0,2,4}）

配置与 checkpoint（一律用 `runlog/W2/freeze_manifest_v2.json` 与 `runlog/W4/baseline_results.csv` 的 SHA256 反查实际路径，加载前后各校验一次）：

| ckpt | checkpoint 来源 | TRC 参数 |
|---|---|---|
| b0 | seed0=`ptxl_gamma08`，seed2/4=`confirm/b0_seed*` | `--trc 0` |
| c1 | `confirm/c1_seed{s}` | `--trc 0` |
| c2 | `confirm/c2_seed{s}` | `--trc 1` |
| simclr | 同 W4 实跑路径（`simclr_seed{s}`） | `--trc 0` |
| clocs | 同 W4 实跑路径（`clocs_seed{s}`） | `--trc 0` |

命令模板（与 W2/W4 同构）：

```powershell
& $PY -u run_lp.py --data-dir data/cpsc --num-classes 9 `
  --checkpoint <上表路径> --feat-dir results/w5/<ckpt>_cpsc_seed{s} `
  --seed {s} --workers 6 --trc <0/1> `
  --extended-metrics 1 `
  --save-predictions runlog/W5/predictions/<ckpt>_cpsc_seed{s} `
  --protocol-id w5-cpscredo
```

**注意**：新分区 = 新 test，旧 CPSC 数字**不会**复现、也不要求复现；PTB/Chapman、缺导、S3 监督行均不受影响，**不要**顺手重跑。S3（监督直训）没有 CPSC 行，不涉及。
